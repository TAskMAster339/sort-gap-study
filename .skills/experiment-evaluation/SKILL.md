# Запуски и оценка

1. Сверить этап, видео и условия с [протоколом](../../docs/protocol.md). Для итогового запуска проверить фиксацию кода, конфигурации и контрольных сумм входов.
2. Использовать отдельный каталог прогона. Сохранить манифест, копию конфигурации, маски, прогнозы и журнал событий. При повторе сравнить метрики и маски.
3. Проверить правила предобработки на примерах из [методов](../../docs/methods.md). Сопоставить метрики с исходными кадрами, включая искусственные пропуски. Сохранить статус видео без оцениваемых Car.
4. Применить правила из [гипотез](../../docs/hypotheses.md). Усреднить реализации внутри видео, сохранить парность при bootstrap и учитывать статусы границ. Проверить поправку Holm на синтетическом примере. В отчёте пилота привести технические результаты без решений по гипотезам.
