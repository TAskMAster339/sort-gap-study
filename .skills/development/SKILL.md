# Выполнение шага разработки

1. Выбрать первый незавершённый пункт в `PLAN.md`. Если плана нет, запросить его у автора. Если все пункты завершены, закончить работу.
2. Выполнить `git status --porcelain=v1 --untracked-files=all`. Если вывод непустой, сообщить автору список изменений и ждать решения. Оставить рабочее дерево и индекс в исходном состоянии.
3. Реализовать выбранный пункт. Добавить или обновить тесты для изменённого поведения.
4. Выполнить `uv run --locked pytest`, `uv run --locked ruff check .`, `uv run --locked ruff format --check .` и `git diff --check`. При ошибках устранить их и повторить проверки. При блокировке оставить пункт открытым и сообщить автору.
5. Просмотреть `git status --short` и diff. Добавить через `git add -- <paths>` только файлы шага. Проверить `git diff --cached --name-only` и `git diff --cached --check`. Создать один локальный коммит с кратким заголовком в формате `feat: add ...`, например `feat: add KITTI dataset reader`.
6. После успешного коммита и проверки чистоты рабочего дерева отметить пункт как выполненный в `PLAN.md` и указать хеш коммита. Сообщить номер пункта, результаты проверок и хеш. Завершить работу.

При первичной настройке среды создать `uv.lock` и подключить pytest и Ruff в рамках выбранного пункта. Включить минимальный тест импорта пакета.
