# Итоговая оценка SORT при серийных пропусках

В итоговую оценку вошли 14 видео из [зафиксированного протокола](protocol.md).
Для каждого видео использовано 481 условие с учётом seed. Все 6 734 маски
построены и использованы для обоих входов и трёх методов. Получено
40 404 прогона со статусом `ok`. Во всех 14 видео есть оцениваемые Car.
Показатели усреднялись сначала по маскам внутри видео, затем по видео
с равными весами.

## H1. Влияние структуры пропусков

При 50% пропусков исходный SORT показал более высокий средний IDF1
при равномерных пропусках, чем при сериях по три кадра. В таблице
приведены парные разности в процентных пунктах.

| Вход | Пар видео | Разность IDF1, п. п. | 95% ДИ, п. п. | p по Holm | Решение |
| --- | ---: | ---: | ---: | ---: | --- |
| GT | 14 | +6,28 | 3,76–8,92 | 0,00120 | H1 поддержана |
| Regionlet | 14 | +5,79 | 4,09–7,60 | 0,00120 | H1 поддержана |

Разность положительна в 12 из 14 видео для GT и во всех 14 видео для
Regionlet. Интервалы рассчитаны по 5 000 парным выборкам целых видео
с seed 0.

## H2. Допустимая длина серии

Длина должна удовлетворять обоим порогам от начала сетки до первой
длины, на которой нарушен один из порогов. RFP измеряется в ложных
срабатываниях на 100 оцениваемых Car.

| Вход | Нижний порог IDF1, % | Потолок RFP | SORT, кадров | SORT-extra, кадров | Разность, кадров | Реплики с двумя конечными границами |
| --- | ---: | ---: | --- | --- | ---: | ---: |
| GT | 67,32 | 67,71 | Не определена | Не определена | — | 242 из 5 000 |
| Regionlet | 53,32 | 172,06 | 1 | 1 | 0 | 4 358 из 5 000 |

Для GT IDF1 уже на длине один кадр ниже порога у обоих методов
(65,01% для SORT и 65,09% для SORT-extra). Поэтому точечная разность
длин и запас RFP на допустимой границе недоступны. Для Regionlet оба
метода проходят ограничения на длине один кадр и нарушают ограничение IDF1
на двух кадрах. Интервал разности длин недоступен для обоих входов по
[критерию конечных границ](hypotheses.md#доверительные-интервалы-и-множественные-проверки).

На выборочной границе SORT-extra в режиме Regionlet запас RFP равен
66,85. Одновременная полоса совместима с длинами 1, 2 и 3 кадра и с
неопределённой границей. 95%-й интервал для запаса при существующей
границе составляет 0,00–193,63. Одностороннее исходное p равно
0,52609, p после Holm равно 1,00. Три недоступные проверки H2 входят
в семейство с условным p = 1 согласно протоколу. Для обоих входов данных недостаточно для поддержки H2.

Дополнительная линейная интерполяция для Regionlet даёт 1,597 кадра
для SORT и 1,620 кадра для SORT-extra. При неопределённых границах GT
пересечение не рассчитывается.

## Описательное сравнение трекеров

Условие в таблице соответствует 50% пропусков сериями по три кадра.
Для каждого метода и входа использованы 30 реализаций маски на видео.

| Вход | Метод | IDF1, % | Среднее FP на видео |
| --- | --- | ---: | ---: |
| GT | SORT | 58,32 | 821,11 |
| GT | SORT-extra | 58,45 | 820,57 |
| GT | OC-SORT | 61,48 | 813,87 |
| Regionlet | SORT | 48,96 | 1 044,06 |
| Regionlet | SORT-extra | 49,11 | 1 042,29 |
| Regionlet | OC-SORT | 51,02 | 1 053,26 |

Адаптер OC-SORT исключил 184 некорректные оценки боксов в 174 прогонах
(64 оценки в 61 прогоне GT и 120 оценок в 113 прогонах Regionlet).
События ассоциации и состояние треков сохранялись по
[правилам адаптера](methods.md#жизненный-цикл-и-oc-sort).
