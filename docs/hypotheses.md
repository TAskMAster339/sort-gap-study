# Гипотезы и критерии проверки

Статус — проект протокола. Правила анализа подлежат проверке на настроечных последовательностях и симуляциях до фиксации итогового протокола.

## Показатели и единица анализа

Основной показатель качества — IDF1 в процентах. Разности IDF1 выражаются в процентных пунктах. Частота ложных срабатываний определяется как `RFP = 100 × FP / N_GT`, где `N_GT` — число оцениваемых экземпляров Car после предобработки KITTI. Участок оценки включает кадры искусственных пропусков и исключает кадры прогрева.

Для каждого условия показатели усредняются по реализациям масок внутри видео, затем по видео с равными весами. Видео с `N_GT = 0` сохраняются в технических результатах и исключаются из всех агрегированных сравнений. Анализ выполняется отдельно для GT и Regionlet. Сравнения методов используют одни и те же видео и маски.

## H1. Влияние структуры пропусков на SORT

При доле пропусков 50% серии из трёх подряд пропущенных кадров дают меньший IDF1 исходного SORT, чем равномерные пропуски.

Для каждого видео из среднего по маскам IDF1 при равномерных пропусках вычитается средний по маскам IDF1 при сериях длиной три кадра. Эффект H1 — среднее этих парных разностей по видео. H1 поддерживается для соответствующего входа, если нижняя граница парного 95%-го доверительного интервала выше нуля и одностороннее значение p после поправки Holm меньше 0,05.

## H2. Допустимая длина серии при дополнительной ассоциации

При доле пропусков 50% дополнительная ассоциация увеличивает допустимую длину серии относительно исходного SORT при соблюдении ограничения на частоту ложных срабатываний.

Для каждого входа по исходному SORT без искусственных пропусков определяются два общих для методов порога. Нижний порог IDF1 равен исходному IDF1 минус 5 процентных пунктов. Верхний порог RFP равен исходному RFP плюс одно ложное срабатывание на 100 оцениваемых экземпляров Car.

На сетке `1, 2, 3, 5, 8, 10` кадров последовательно проверяются **точечные** средние IDF1 и RFP. Длина проходит критерий при IDF1 не ниже порога и RFP не выше потолка. Допустимая область включает только длины перед первым нарушением.

| Статус | Условие | Отчёт |
| --- | --- | --- |
| Конечная граница | Начальные длины проходят, затем следует нарушение | Последняя пройденная длина перед первым нарушением |
| Нижняя граница | Вся сетка пройдена | Допустимая длина не меньше 10 кадров |
| Неопределённая граница | Минимальная длина не проходит | Допустимая длина в проверенной сетке не установлена |

Эффект по длине — допустимая длина модифицированного SORT минус допустимая длина исходного SORT. Численная разность рассчитывается при двух конечных границах. Для остальных сочетаний сообщаются статусы обоих методов. Если оба метода проходят всю сетку, увеличение предельной длительности не установлено.

Ограничение FP проверяется отдельно. Запас до потолка равен разности между потолком RFP и средним RFP модифицированного SORT на его выбранной допустимой длине. H2 поддерживается для соответствующего входа при одновременном выполнении двух условий:

- Нижняя граница парного 95%-го интервала разности длин выше нуля и скорректированное p меньше 0,05.
- Нижняя граница 95%-го интервала запаса до потолка RFP выше нуля и скорректированное p меньше 0,05.

Линейная интерполяция первого пересечения порога относится к дополнительному анализу. Решение по H2 принимается по проверенным длинам.

## Доверительные интервалы и множественные проверки

Используются 5000 bootstrap-выборок целых видео с возвращением и общими индексами для сравниваемых условий. В каждой реплике заново рассчитываются пороги, кривые, допустимые длины и запас RFP. Доверительные интервалы задаются квантилями 2,5% и 97,5%. Если численная разность длин не определена в исходной оценке или хотя бы в одной реплике, интервал разности не рассчитывается и приводятся частоты статусов. Интервал запаса RFP рассчитывается при наличии выбранной длины в исходной оценке и во всех репликах.

Для положительного направления эффекта используется одностороннее центрированное bootstrap-значение `p = (1 + count(θ* − θ̂ ≥ θ̂)) / (B + 1)`, где `θ̂` — точечная оценка, `θ*` — оценка в реплике, `B = 5000`. К шести значениям p применяется поправка Holm:

1. H1 — разность IDF1, GT.
2. H1 — разность IDF1, Regionlet.
3. H2 — разность допустимых длин, GT.
4. H2 — запас до потолка RFP, GT.
5. H2 — разность допустимых длин, Regionlet.
6. H2 — запас до потолка RFP, Regionlet.

При невозможности рассчитать проверку ей присваивается p = 1 для сохранения размера семейства. OC-SORT, прочие доли и режимы пропусков анализируются описательно. Решения по гипотезам принимаются по итоговым последовательностям после фиксации протокола.
