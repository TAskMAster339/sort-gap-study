# Протокол эксперимента

Статус — проект протокола. Значения, указанные для пилота, подлежат проверке на настроечных последовательностях. Итоговая оценка начинается после фиксации протокола.

## Данные и разделение

Используется размеченная часть KITTI Tracking. Длины последовательностей берутся из training seqmap. Набор разделяется по целым видео.

| Часть | Последовательности |
| --- | --- |
| Настроечная | `0000`, `0002`, `0005`, `0009`, `0011`, `0017`, `0019` |
| Итоговая | `0001`, `0003`, `0004`, `0006`, `0007`, `0008`, `0010`, `0012`, `0013`, `0014`, `0015`, `0016`, `0018`, `0020` |

Настроечная часть используется для отладки, выбора порога Regionlet, параметров фильтра и ассоциации, настройки жизненного цикла и оценки точности интервалов. До фиксации на итоговой части допускается аудит файлов, диапазонов кадров и состава разметки. Итоговые прогнозы и метрики рассчитываются после фиксации.

Сравниваются SORT, SORT с дополнительной ассоциацией и OC-SORT. Для каждого метода предусмотрены два входа — прямоугольники GT без идентификаторов и детекции Regionlet. Форматы входов и правила оценки описаны в [методах](methods.md).

## Временная шкала и маски

Кадры 0–9 используются для прогрева с доступными наблюдениями и исключаются из метрик. При длине участка оценки `N` и доле потерь `p` пропускаются ровно `K = floor(p × N + 0.5)` наблюдений. Номера кадров и разметка сохраняются. На каждом исходном кадре выполняется шаг трекера. Искусственный пропуск передаётся как пустой массив детекций с отдельным признаком.

- Равномерная маска распределяет `K` пропусков по участку оценки со сдвигом фазы, определённым seed. При `K > 0` индекс внутри участка равен `floor((j + phase) × N / K)` для `j = 0, …, K − 1`, где `0 ≤ phase < 1`.
- Случайная маска выбирает `K` кадров без возвращения.
- Серийная маска размещает блоки длиной `L` и один укороченный блок при ненулевом остатке. Между соседними блоками сохраняется хотя бы один доступный кадр. При `K + число блоков − 1 > N` условие отмечается как невозможное.
- Маска формируется один раз на сочетание видео, условия и seed. Все методы и оба входа используют одинаковые маски. В артефакте сохраняются исходные номера пропусков и фактические длины серий. Серия в конце видео может завершиться без следующего доступного кадра.

При частоте 10 Гц длительность серии из `L` кадров составляет `L / 10` с. Интервал между двумя доступными кадрами, окружающими серию, составляет `(L + 1) / 10` с.

## Сетка условий

| Этап | Доля пропусков | Условия | Seed |
| --- | --- | --- | --- |
| Технический пилот | 0% | Без маски | Один запуск |
| Технический пилот | 50% | Равномерные, случайные, серии по 3 и 10 кадров | 0 и 1 |
| Полная сетка | 0% | Без маски | Один запуск |
| Полная сетка | 25% и 75% | Равномерные, случайные, серии по 3 и 5 кадров | 0–29 |
| Полная сетка | 50% | Равномерные, случайные, серии по 1, 2, 3, 5, 8 и 10 кадров | 0–29 |

Правила H1, H2, интервальной оценки и поправки Holm заданы в [гипотезах](hypotheses.md).

## Пилот и фиксация

1. Выполнить сквозной запуск на `0000` с GT и SORT при 0% пропусков и при 50% пропусков сериями по три кадра.
2. Выполнить сокращённый пилот на настроечных видео с тремя методами и двумя входами. Проверить точный бюджет пропусков, фактические длины серий, исходную нумерацию и совпадение масок.
3. Сохранить примеры прогнозов внутри паузы, ассоциаций на первом доступном кадре, событий создания и удаления треков и пробных метрик. Проверить повторяемость результатов и оценить точность интервалов для планируемого числа итоговых видео.
4. Зафиксировать код, конфигурацию, список видео, сетку, seed, версии зависимостей и контрольные суммы входов. Выполнить итоговую оценку с проверкой соответствия зафиксированному состоянию.

Для каждого запуска сохраняются манифест, конфигурация, маски, прогнозы KITTI, журнал событий и таблица метрик. Компактные отчёты пилотов хранятся в `docs/pilots/`. Полные артефакты хранятся в локальном каталоге `runs/`.
