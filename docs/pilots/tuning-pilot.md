# Сокращённый пилот SORT, SORT-extra и OC-SORT

## Условия

Пилот выполнен на настроечных видео KITTI Tracking `0000`, `0002`, `0005`,
`0009`, `0011`, `0017` и `0019`. Для каждого видео использованы
два источника детекций, GT без идентификаторов и Regionlet с порогом
`score ≥ 0.0`. TrackEval получал полную разметку соответствующего видео.
Кадры `0–9` использованы для прогрева. Исходные индексы сохранены во всех
прогнозах и журналах.

| Доля пропусков | Тип маски | Длина серии | Seed | Условий на видео |
| --- | --- | --- | --- | ---: |
| 0% | Без пропусков | — | — | 1 |
| 50% | Равномерная | — | 0, 1 | 2 |
| 50% | Случайная | — | 0, 1 | 2 |
| 50% | Серийная | 3 | 0, 1 | 2 |
| 50% | Серийная | 10 | 0, 1 | 2 |

Для каждого сочетания видео, условия и seed маска была рассчитана один раз.
Три метода получили её в обоих режимах входа. Для 63 масок сверены бюджет
пропусков, отсутствие пропусков на прогреве и совпадение файлов маски между
режимами и методами. Для каждого прогона сверены исходная нумерация журнала
и номера кадров с признаком `artificial_gap`.

## Результаты запуска

Завершены все 378 прогонов, по 189 на источник детекций и по 126 на метод.
Для каждого прогона получен отдельный CSV TrackEval. Значения в сводной
таблице сверены с отдельными CSV.

| Видео | Кадров оценки | Оцениваемых экземпляров Car | Строк метрик | Статус |
| --- | ---: | ---: | ---: | --- |
| `0000` | 145 | 215 | 54 | `ok` |
| `0002` | 224 | 984 | 54 | `ok` |
| `0005` | 288 | 1174 | 54 | `ok` |
| `0009` | 794 | 2428 | 54 | `ok` |
| `0011` | 364 | 2809 | 54 | `ok` |
| `0017` | 136 | 0 | 54 | `no_ground_truth` |
| `0019` | 1050 | 819 | 54 | `ok` |

В таблице 324 строки с оцениваемыми экземплярами Car. Все 54 строки видео
`0017` сохранены с пустым полем RFP. Для агрегированных сравнений протокол
предусматривает шесть видео. [Правила агрегирования](../hypotheses.md)

Полная таблица `metrics.csv` содержит по одной строке на сочетание видео,
условия, входа и метода. В таблицу перенесены IDF1, HOTA, DetA, AssA, FP, FN,
IDSW, Frag, RFP, число оцениваемых кадров и число экземпляров Car после
предобработки.

## Артефакты и воспроизведение

Рабочий каталог пилота — `runs/pilot-tune-5.1/`. Файл `pilot.json` содержит
список условий и SHA-256 входных файлов. На уровне
`<видео>/<условие>/<вход>/<метод>/` сохранены манифест, копия конфигурации,
маска, прогнозы KITTI, журнал JSONL и метрики TrackEval.

- Код запуска — `2e8d27b949e5b745f73459358d3f1a544295f018`.
- OC-SORT — `8462e7e729a93ccd3bd995c0a79a890336cb3a0b`.
- TrackEval — `12c8791b303e0a0b50f753af204249e622d0281a`.
- Параметры — `configs/protocol.toml`. Версии Python и зависимостей записаны
  в манифестах прогонов.
- SHA-256 сводной таблицы — `d2f5245e89cba77332150e87460460a97cb7cbfa05aa718380a3831906459eb7`.
- SHA-256 сценария `run-pilot.py` — `a1c0a82b9768110bbc01b7ea8c6f86eee828ce18f9c743632fc09cec95f0ec8d`.

Для повторения укажите пути к входам и новый каталог результатов. Локальные
копии OC-SORT и TrackEval подготавливаются по [README](../../README.md).

```bash
OPENBLAS_NUM_THREADS=1 uv run --locked python runs/pilot-tune-5.1/run-pilot.py \
  --config configs/protocol.toml \
  --seqmap /path/to/evaluate_tracking.seqmap.training \
  --labels /path/to/label_02 \
  --regionlet /path/to/det_02 \
  --output runs/pilot-tune-5.1-repeat
```
