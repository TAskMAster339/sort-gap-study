# Настройка на полной сетке и точность интервалов

## Условия

Выполнен настроечный прогон SORT, SORT-extra и OC-SORT на входах GT и
Regionlet. Использованы семь видео из настроечного split. Для каждого видео
проверены 481 условие полного протокола. Базовый прогон использовал 0%
пропусков. Условия с 25%, 50% и 75% пропусков использовали по 30 seed,
`0–29`. Маска каждого сочетания видео, условия и seed общая для обоих
входов и трёх методов. Прогрев составил десять кадров.

Проверены **3 367 масок и 20 202 прогона**. Из них 17 316 относятся к
видео с оцениваемыми Car и 2 886 — к видео `0017` со статусом
`no_ground_truth`. Для сравнения методов использованы шесть видео.
Исполняемые параметры из `configs/protocol.toml` использованы без
дополнительного подбора. [Полная сетка](../protocol.md#сетка-условий)

Первый запуск обнаружил некорректные оценки боксов OC-SORT. Адаптер
записывает их ID в `invalid_estimates` и пропускает эти боксы в экспорте.
События ассоциации и состояние трека сохраняются. Полный набор метрик
получен на одной ревизии с этим исправлением.

Зарегистрировано 15 исключённых оценок в 15 прогонах OC-SORT. Из них 1 относится к GT и 14 — к Regionlet.

## Поведение H2 на синтетических данных

Для каждого сценария с известными средними сгенерированы 300 выборок из
14 видео. Для показателей каждого видео использованы общий нормально
распределённый сдвиг и локальный шум по методу и длине. Границы и запас
пересчитывались на 5 000 bootstrap-реплик в каждой выборке. Интервалы
оценивались по доступности и покрытию известного значения модели.
Генерирующие параметры сохранены в `h2-simulations.json`.

| Сценарий | Интервал разности доступен | Покрытие разности среди доступных | Медианная ширина, кадров |
| --- | ---: | ---: | ---: |
| Две устойчивые конечные границы | 300 / 300 | 300 / 300 | 0 |
| Внутренняя граница близка к порогу IDF1 | 300 / 300 | 292 / 300 | 6 |
| Внутренняя граница близка к потолку RFP | 300 / 300 | 297 / 300 | 3 |
| Одна граница устойчива как неопределённая или нижняя | 0 / 300 в каждом сценарии | — | — |
| Возможен переход в неопределённую границу | 1 / 300 | 1 / 1 | 0 |
| Возможен переход в нижнюю границу | 3 / 300 | 3 / 3 | 0 |

Нулевая ширина в устойчивом сценарии соответствует одинаковому
дискретному ответу во всех репликах. При устойчивой конечной границе
95%-й интервал запаса RFP накрыл заданное значение в 272 из 300
симуляций (90,7%).

При истинном запасе RFP, равном нулю, интервал запаса на выбранной
длине исключил ноль во всех 300 симуляциях. Положительный нижний предел
вместе с нескорректированным `p < 0,05` получен в 162 случаях из 300
при нулевой истинной разности длин. В сценарии с истинным выигрышем
7 кадров и нулевым запасом RFP совместное правило H2 с поправкой Holm
сработало в 156 из 300 выборок. В этом сценарии четырём остальным
проверкам семейства задано `p=1`.

Выбор длины ограничивает все доступные bootstrap-значения запаса снизу
нулём по самому условию допуска. При непрерывном шуме точное равенство
порогу почти не встречается, поэтому нижняя граница процентильного
интервала может быть положительной за счёт отбора. Текущее правило
запаса RFP требует пересмотра до фиксации подтверждающей проверки H2.
Приведённые частоты относятся к заданным симуляциям. [Контекст учёта отбора при статистическом выводе](https://pmc.ncbi.nlm.nih.gov/articles/PMC4207812/)

## Правило дополнительной интерполяции

Для каждой длины рассчитываются два знаковых запаса. Запас IDF1 равен
разности между средним IDF1 и нижним порогом. Запас RFP равен разности
между верхним порогом и средним RFP. Допустимый проверенный префикс
состоит из длин, на которых оба запаса неотрицательны.

Для конечной дискретной границы интерполяция использует две соседние
длины, последнюю прошедшую `L₀` и первую нарушившую `L₁`. Для каждого нарушившего
ограничения с запасами `g₀ ≥ 0` и `g₁ < 0` пересечение оценивается как
`L₀ + (L₁ − L₀) × g₀ / (g₀ − g₁)`. При нарушении обоих ограничений
используется меньшее из двух пересечений. Нулевой запас на `L₀` даёт
пересечение на самой `L₀`.

При неопределённой или нижней границе сохраняется дискретный статус, а
точка пересечения отсутствует. Если оценивать интервал интерполированной
разности, в каждой bootstrap-реплике заново выбираются пороги и
соседние длины. Интервал выводится при наличии двух пересечений в
точечной оценке и во всех репликах. Решение по H2 следует дискретной
проверке по сетке. На настроечной выборке пересечения для SORT и
SORT-extra составили соответственно 1,245 и 1,248 кадра для GT и
2,849 и 2,878 кадра для Regionlet. [Правила принятия решения](../hypotheses.md)
