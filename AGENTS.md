# Правила работы над sort-gap-study

- Для каждого шага разработки применять [навык development](.skills/development/SKILL.md).
- Локальная очередь разработки хранится в корневом `PLAN.md`. Если файла нет, запросить его у автора и приостановить работу.
- Научные материалы хранятся в `docs/`, исполняемые параметры в `configs/`, код в `src/sort_gap_study/`, тесты в `tests/`.
- Писать в формальном научном стиле. Фиксировать гипотезы, параметры, процедуры и результаты. Обоснования добавляет автор.
- Отладка, подбор параметров и пилоты используют настроечные видео. Итоговая оценка использует зафиксированные код, данные и протокол.
- Сохранять исходные номера кадров, полную разметку для оценки и общие маски для всех методов. Исключать GT ID из входа трекеров и сохранять ранее выданные прогнозы.
- Добавлять в Git явные пути. Хранить в Git исходный код, тесты, конфигурацию, `uv.lock` и научную документацию. Данные, сторонние исходники, полные результаты прогонов и локальный план хранить отдельно.
