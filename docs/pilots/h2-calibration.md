# Проверка итогового правила запаса RFP

Использованы те же девять синтетических моделей, что и для проверки
[на полной настроечной сетке](full-tuning.md#поведение-h2-на-синтетических-данных).
В каждой модели получено 300 выборок по 14 видео. Seed генерации равен
5721. В каждой выборке выполнено 5000 парных bootstrap-реплик. Для
оценки совместного правила H2 четырём прочим проверкам семейства
присвоено `p = 1`. Истинный запас задан у границы, рассчитанной по
средним модели.

| Сценарий | Истинная разность, кадров | Истинный запас RFP | Покрытие запаса, из 300 | Поддержка H2, из 300 |
| --- | ---: | ---: | ---: | ---: |
| Устойчивые конечные границы | 2 | 3 | 293 | 300 |
| Граница близка к порогу IDF1 | 2 | 3 | 300 | 2 |
| Граница близка к потолку RFP | 2 | 0,25 | 300 | 0 |
| Нулевые разность и запас | 0 | 0 | 289 | 0 |
| Положительная разность и нулевой запас | 7 | 0 | 290 | 2 |

В сценарии с выигрышем 7 кадров и нулевым запасом исходное правило
поддержало H2 в 156 из 300 выборок. Промежуточное правило с одновременной
полосой RFP только на выбранной длине дало 146 из 300. При переходе
выборочной границы на более короткую длину её истинный запас мог быть
положительным. Итоговое правило оценивает запас по всем границам,
совместимым с одновременной полосой IDF1 и RFP, и дало 2 из 300.

При слабом запасе и близости к порогам совместное правило редко
поддерживает H2. Симуляция характеризует заданные модели. Для дискретной
разности длин сохраняются требования к конечным границам и ограничения
бутстрепа вблизи порогов. Генерирующие параметры, скрипт и полный
результат находятся локально в `runs/protocol-6.2-validation/`.
Итоговые прогнозы и метрики для этой проверки не использовались.
