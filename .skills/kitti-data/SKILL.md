# Данные KITTI и маски

1. Сверить списки видео и правила масок с [протоколом](../../docs/protocol.md), форматы входов — с [методами](../../docs/methods.md).
2. Проверить длины по seqmap, диапазоны кадров и принадлежность видео к части эксперимента. Сохранить исходные номера, включая кадры без строк детекций.
3. Проверить на малых примерах фильтрацию GT и Regionlet. Трекер получает массив из пяти столбцов. Полная разметка для оценки хранится отдельно.
4. Проверить точное число пропусков после прогрева, фактические длины серий, воспроизводимость по seed и явный статус невозможных условий. Сравнить сохранённые маски для всех методов и обоих режимов входа.
